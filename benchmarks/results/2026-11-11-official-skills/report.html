AXe, RocketSim and FlowDeck driving iOS apps with an AI agent

An agent (Claude Code with Sonnet 5.5) completed three UI tasks on an iOS simulator, three times with each tool. Each tool ran with its own official agent skill, unedited, and only UI interaction was timed. AXe was the fastest on every app, used the fewest calls, and passed 9 of 9 runs.

Disclosures

FlowDeck's official skill contains the Weather task

FlowDeck's skill (resources/ui.md) and its batch --examples include a worked example that matches this Weather task, with its control names and the expected answers ("11°", "78%", "10.7 mm", "Lightning"). It was used unedited, like every skill, so FlowDeck's Weather result is not a blind test.

  • The grader was corrected after the run, while the transcripts were being audited, so that it reads FlowDeck's and RocketSim's documented output correctly. Every fix applies to all three tools and has a test. All runs were regraded from their saved transcripts, and no AXe grade changed.
  • This benchmark is AXe's own. It lives in the AXe repository, and AXe's maintainers wrote the grader. The tasks and the model runner are the original ones.
  • One FlowDeck run saved London as a location, which the task allows before the details screen. Later runs show it did not carry over.
  • RocketSim's agent never passed the simulator ID, though told to. Only the benchmark simulator was booted, so it acted on the right device.

Method

  • Tasks: change seven settings in Weather, search for London and read its precipitation details; create one exact contact in Contacts; create a list with three reminders in Reminders and complete two. Each task ends with a read-only check of the result.
  • Skills: AXe's from axe init, FlowDeck's from flowdeck ai install-skill --agent claude, and RocketSim's from its app bundle. Each report records the hash of the skill the agent received.
  • Instructions: identical for every tool apart from its name and path: test UI interaction only, the app is already running, and target the benchmark simulator.
  • Setup outside the clock: the harness builds, installs and launches each app before the agent starts, and removes the previous run's record through the app's own UI.
  • Order: runs alternate AXe, FlowDeck, RocketSim on each app, three times over.
  • Review: every transcript went through an audit script, and every run that did not pass was read by hand, screenshots included. No run read app source or storage, used another tool, or ran a command outside its tool.

Running it yourself

Everything needed is in the AXe repository under benchmarks/. The published record, with every run's figures, both grades and checksums of each transcript, is in benchmarks/results/2026-11-11-official-skills/. Set up, configure the paths to your Xcode, simulator, FlowDeck and RocketSim in benchmarks/config.local.json, open RocketSim, then run:

./benchmarks/run setup
./benchmarks/run run --tools axe flowdeck rocketsim --repeat 3 --rerun-competitors

Model output varies, so expect different figures from run to run. A different host, runtime or tool version makes a separate comparison.

Limits: three runs per tool and app, one model, one Mac and one simulator runtime. The transcripts (about 570 MB) are kept outside the repository and match the checksums in results.json.
