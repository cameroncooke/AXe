# Contributing to AXe

Thanks for considering a contribution. Bug reports, fixes and new features are welcome as issues and pull requests on GitHub.

Before you start on a large change, open an issue to discuss it. Read [AGENTS.md](AGENTS.md) for the code, test and changelog rules, and the Development section of the [README](README.md#development) for building and testing.
