OVERVIEW: Install the AXe skill directly or through the Claude Code or Codex
marketplace.

USAGE: axe init [--client <client>] [--dest <dest>] [--force] [--uninstall] [--print]

OPTIONS:
  --client <client>       Target client: auto, agents, claude, or codex.
                          Defaults to auto-detect. (values: auto, agents,
                          claude, codex; default: auto)
  --dest <dest>           Custom destination skills directory instead of a
                          marketplace.
  --force                 Reinstall the marketplace plugin or overwrite a
                          custom destination.
  --uninstall             Uninstall the marketplace plugin or custom skill.
  --print                 Print bundled skill content to stdout.
  --version               Show the version.
  -h, --help              Show help information.
